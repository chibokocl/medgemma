## What is this?

`medgemma` is a command-line tool and Python library that runs Google's [MedGemma 4B-IT](https://huggingface.co/google/medgemma-4b-it) medical AI model **entirely on your Mac**. It uses Apple's [MLX framework](https://ml-explore.github.io/mlx/) to run inference on your Apple Silicon GPU — no cloud API, no data leaves your machine.

Ask medical questions, analyze medical images, and get evidence-based responses — all from your terminal or Python code.

## Features

- **Fully local** — all inference runs on-device via MLX; nothing is sent to external servers
- **Multimodal** — analyze medical images (X-rays, scans, photos) alongside text prompts
- **Streaming** — real-time token streaming in the terminal and Python API
- **4-bit quantized** — ~4 GB footprint vs. ~8 GB for the original weights, with minimal quality loss
- **Simple CLI** — one command to set up, one command to ask
- **Python API** — import `MedGemma` directly for use in scripts, notebooks, or applications
- **JSON output** — structured output with generation statistics for programmatic use

## Requirements

- **Apple Silicon Mac** (M1, M2, M3, or M4)
- **Python 3.10** or newer
- **~4 GB free disk space** for the quantized model weights
- **Hugging Face account** with the MedGemma license accepted (free — see setup below)

## Quick Start

### 1. Install

```bash
pip install medgemma
```

Or with [uv](https://docs.astral.sh/uv/):

```bash
uv pip install medgemma
```

### 2. Accept the model license on Hugging Face

The weights are gated by Google's license. You must accept it once:

1. Create a free [Hugging Face account](https://huggingface.co/join)
2. Visit [google/medgemma-4b-it](https://huggingface.co/google/medgemma-4b-it) and click **Agree and access repository**
3. Authenticate your local machine:

```bash
pip install huggingface-hub   # skip if already installed
huggingface-cli login
```

You only need to do this once per machine.

### 3. Download and prepare the model

```bash
medgemma setup
```

This downloads the MedGemma 4B model from Hugging Face, converts it to 4-bit quantized MLX format, and caches it at `~/.medgemma/model`. Takes a few minutes on first run; subsequent runs are instant.

### 4. Ask a question

```bash
medgemma ask "What are the common symptoms of type 2 diabetes?"
```

Example output:

## CLI Reference

### `medgemma ask`

Send a prompt (and optional image) to the model.

```
medgemma ask PROMPT [OPTIONS]
```

| Option | Default | Description |
|---|---|---|
| `--image PATH` | — | Path to an image file to analyze alongside the prompt |
| `--max-tokens INT` | 512 | Maximum number of tokens to generate |
| `--temperature FLOAT` | 0.1 | Sampling temperature (lower = more deterministic) |
| `--model-path PATH` | `~/.medgemma/model` | Use a specific local MLX model directory |
| `--json` | false | Output full response as JSON with generation stats |
| `--no-stream` | false | Collect the full response before printing (disables streaming) |

### `medgemma setup`

Download the MedGemma model and convert it to MLX format. Safe to run again — skips download if the cache already exists unless `--force` is passed.

```
medgemma setup [OPTIONS]
```

| Option | Description |
|---|---|
| `--local-path PATH` | Use an already-converted local MLX model instead of downloading |
| `--force` | Re-download and overwrite an existing cached model |

### `medgemma info`

Show model status and cache location.

```
medgemma info
```

Example output:

```
Cache directory : /Users/you/.medgemma/model
Model in cache  : yes
Model loaded    : no
```

When a model is actively loaded:

```
Cache directory : /Users/you/.medgemma/model
Model in cache  : yes
Model loaded    : yes
Loaded from     : /Users/you/.medgemma/model
```

### `medgemma --version`

Print the installed version.

## Python API

### Basic usage

```python
from medgemma import MedGemma

mg = MedGemma()
response = mg.ask("What are symptoms of diabetes?")
print(response.text)
```

### Image analysis

```python
response = mg.ask("Describe this X-ray", image="chest_xray.png")
print(response.text)
```

### Streaming

```python
for chunk in mg.stream("Explain hypertension"):
    print(chunk, end="", flush=True)
print()  # newline after stream ends
```

Streaming also supports images:

```python
for chunk in mg.stream("What do you see in this image?", image="scan.png"):
    print(chunk, end="", flush=True)
```

### Per-call parameter overrides

Parameters set on the `MedGemma` instance are defaults; you can override them per call:

```python
mg = MedGemma(max_tokens=512, temperature=0.1)

# This call uses higher token limit and more creative temperature
response = mg.ask("Describe hypertension treatment options", max_tokens=1024, temperature=0.4)
```

### Response object

`MedGemma.ask()` returns a `Response` dataclass:

| Field | Type | Description |
|---|---|---|
| `text` | `str` | The generated response text |
| `prompt_tokens` | `int` | Number of tokens in the prompt |
| `completion_tokens` | `int` | Number of tokens generated |
| `tokens_per_second` | `float` | Generation speed |
| `elapsed_seconds` | `float` | Total generation time in seconds |

```python
response = mg.ask("What is aspirin used for?")
print(response.text)
print(f"{response.completion_tokens} tokens in {response.elapsed_seconds:.1f}s")
print(f"Speed: {response.tokens_per_second:.1f} tok/s")
```

### Custom model path and parameters

```python
mg = MedGemma(
    model_path="/path/to/local/mlx-model",
    max_tokens=1024,
    temperature=0.3,
)
```

### Check model status

```python
info = MedGemma.info()
print(info.cache_dir)    # Path to cache directory
print(info.cache_ready)  # True if model is downloaded
print(info.loaded)       # True if model is in memory
print(info.path)         # Path of the currently loaded model (or None)
```

### Release model from memory

```python
mg.unload()
```

## How It Works

1. **Download** — `medgemma setup` fetches [google/medgemma-4b-it](https://huggingface.co/google/medgemma-4b-it) from Hugging Face.
2. **Quantize** — The weights are converted to 4-bit quantized MLX format (group size 64), shrinking from ~8 GB to ~4 GB with minimal quality loss.
3. **Cache** — The converted model is stored at `~/.medgemma/model` and reused on every subsequent run.
4. **Infer** — All inference runs on your Apple Silicon GPU via [MLX-VLM](https://github.com/Blaizzy/mlx-vlm). No data is sent to any server.
5. **Lazy load** — The model is loaded into memory on the first `ask()` or `stream()` call, then kept loaded for subsequent requests in the same process.

## Troubleshooting

### "Not running on Apple Silicon"

MedGemma requires an Apple Silicon Mac (M1/M2/M3/M4). The MLX framework only supports Apple's ARM-based chips. It cannot run on Intel Macs or other platforms.

### Model download fails

- Confirm you accepted the license at [google/medgemma-4b-it](https://huggingface.co/google/medgemma-4b-it) and ran `huggingface-cli login`
- Check your internet connection and that you have ~4 GB of free disk space
- Retry with `medgemma setup --force` to start fresh
- If behind a firewall, download the model manually and use `medgemma setup --local-path /path/to/model`

### Out of memory

The 4-bit quantized model requires approximately 4 GB of unified memory. If generation fails or is very slow:

- Close other memory-intensive applications
- Use `--max-tokens` with a lower value to limit output length
- Call `mg.unload()` in Python when finished to release memory

### First inference is slow

The first `ask` or `stream` call loads the model into GPU memory, which can take 5–15 seconds depending on your hardware. All subsequent calls in the same process reuse the loaded model and are much faster.

### `huggingface-cli` not found

Install the Hugging Face Hub CLI:

```bash
pip install huggingface-hub
```
